Privacy Policy

This policy describes information handled by NIMBLE Race Control, a community-operated Discord racing bot.

1. Data collected

When the bot is configured and used, it may store: Discord server ID; Discord user IDs for registered drivers, officials, and race-result participants; role and channel IDs; driver registration status; race event identifiers, names, dates, divisions, and finishing positions; XP balances, levels, rank assignments, and correction or result history; and timestamps and staff user IDs associated with official changes.

The bot does not require your Discord password, CPM2 account password, payment information, or private messages. The supplied starter version does not use chat messages for automatic XP.

2. How data is used

This information is used only to run server racing operations: verify authorized officials, register competitors, calculate XP, prevent duplicate awards, assign Discord roles, provide profiles and leaderboards, investigate disputes, and publish official race results.

3. Visibility and sharing

Driver display names/mentions, finishing positions, race results, XP, levels, and classifications may appear in server channels available to community members. Authorized server administrators and bot operators can access the local records. Discord receives information through the bot's normal API requests needed to perform these functions. The operator does not sell racing data.

4. Storage and retention

The starter bot stores its data in a SQLite database on the computer or hosting service running NIMBLE Race Control. Records may remain there while needed to run competitions and preserve standings. The starter does not include an automatic expiry period for driver records. Administrators are responsible for removing information when no longer necessary, when the bot is discontinued, or upon a valid deletion request. Backups, if created, must also be managed by the operator.

5. Requests to access, correct, or delete data

Contact the NIMBLE Racing Team Team Owner or TeamManager in the community Discord server and request access, correction, or deletion of your bot records. Include your Discord user ID or otherwise identify your server membership. Do not send passwords or private account credentials. Administrators must process requests through their bot/database administration procedures; the starter bot does not currently offer a self-service deletion command.

6. Security

Bot access is restricted by Discord permissions and authorized staff roles, and the bot token should be stored privately. The local SQLite file is not inherently encrypted, so access to the host system and backups must be protected by the operator. No security system can guarantee absolute protection.

7. Updates and contact

This policy may be updated if the bot gains additional functionality or changes its data practices. Questions may be directed to the NIMBLE Racing Team server's Team Owner or TeamManager through Discord.
